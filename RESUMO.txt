          HUBSABIA - RESUMO DO PROJETO (atualizado 2026-08)

ESTRUTURA
------------------------------------------------------------
 HubSabia/ (Monorepo npm workspaces)
   +-- frontend/   -> Vue 3 + Vite (porta 5173)
   +-- backend/    -> Node.js + Express + MongoDB (porta 3001)

TECNOLOGIAS
------------------------------------------------------------
Frontend: Vue 3.4+, Vite 5, Vue Router 4, Axios, Tailwind (instalado, nao usado)
Backend:  Node >= 20, Express 4, Mongoose 8, JWT, bcrypt
IA:       Gemini (padrao) + OpenAI (fallback); chave propria do usuario opcional
RAG:      pdf-parse (extracao) -> chunking 800 chars -> embeddings
          (Gemini ou local Xenova) -> busca hibrida (vetorial + keywords) -> resposta

COMO RODAR LOCALMENTE
------------------------------------------------------------
1. npm install
2. cp backend/.env.example backend/.env  (preencher MONGODB_URI, JWT_SECRET, GEMINI_API_KEY)
   cp frontend/.env.example frontend/.env
3. npm run dev

Frontend: http://localhost:5173
Backend:  http://localhost:3001/api/health

ENDPOINTS DA API
------------------------------------------------------------
AUTH:
  POST   /api/auth/register            Registrar usuario
  POST   /api/auth/login               Login
  GET    /api/auth/me                  Dados do usuario atual
  POST   /api/auth/profile             Atualizar perfil
  POST   /api/auth/provider-config     Configurar chave de API (gemini/openai)
  POST   /api/auth/provider-preference Preferencia de provider
  POST   /api/auth/acknowledge-plan    Aceitar plano atual
  GET    /api/auth/users               Listar usuarios (admin)
  DELETE /api/auth/users/:id           Deletar usuario (admin)

EDITAIS:
  POST   /api/edital/upload            Upload de PDF ou conteudo manual (admin)
  GET    /api/editais                  Lista de editais
  GET    /api/edital/:id               Detalhes de um edital
  GET    /api/edital/:id/chunks        Trechos de um edital
  DELETE /api/edital/:id               Deletar edital (admin)

CHAT:
  POST   /api/chat/pergunta            Fazer pergunta (RAG)
  POST   /api/chat/pergunta/stream     Streaming (SSE)
  GET    /api/chat/conversas           Conversas do usuario
  GET    /api/chat/conversa/:id        Mensagens de uma conversa
  POST   /api/chat/feedback            Avaliar resposta (logado)
  GET    /api/chat/sugestoes/:id       Perguntas sugeridas
  GET    /api/chat/historico           Historico (admin ou proprio)

OUTROS:
  GET    /api/health                   Saude do servidor
  POST   /api/logs/error               Log de erros do frontend

CREDITOS E PLANOS
------------------------------------------------------------
- 20 creditos diarios por usuario (reset automatico a cada 24h)
- Chave propria (gemini/openai) no perfil -> uso ilimitado
- Visitantes usam o chat sem limite de creditos
- Plano atual: gratuito; selecao exibida na primeira visita logada

ADMIN
------------------------------------------------------------
Criar/atualizar admin:  npm run create-admin --workspace=backend
  (email via ADMIN_EMAIL, senha via ADMIN_PASSWORD ou gerada aleatoria impressa no console)

SEGURANCA
------------------------------------------------------------
- JWT_SECRET OBRIGATORIO (backend recusa iniciar sem ele; nunca commitar)
- Chaves de API dos usuarios armazenadas no banco (nao expostas na API)
- Erros de provider sao sanitizados (API keys redigidas) antes de logar
- errorHandler nao persiste corpo de requisicao (senhas/chaves)
- /api/debug disponivel apenas em desenvolvimento

DEPLOY
------------------------------------------------------------
Backend: Render (Node) - npm start (backend/src/server.js)
Frontend: Vercel - VITE_API_URL=/api com proxy, ou URL direta do backend
